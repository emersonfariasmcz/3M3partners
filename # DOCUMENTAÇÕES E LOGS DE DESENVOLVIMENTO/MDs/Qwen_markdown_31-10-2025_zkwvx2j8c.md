# Documentação Técnica - Sistema de Controle de Estoque IGA

## 1. Visão Geral do Projeto

### 1.1. Objetivo
Desenvolver um sistema web para controle de estoque de produtos em unidades de saúde, permitindo o gerenciamento de entradas, saídas, cadastros auxiliares e geração de relatórios gerenciais.

### 1.2. Público-Alvo
Gestores de unidades de saúde e funcionários responsáveis pelo controle de estoque.

### 1.3. Tecnologias Empregadas
*   **Frontend:**
    *   HTML5
    *   CSS3
    *   JavaScript (Vanilla)
    *   Bootstrap 5.3.0
    *   Font Awesome 6.0.0
*   **Backend:**
    *   PHP 8.2+
    *   PDO para acesso ao banco de dados
    *   Arquitetura MVC (Model-View-Controller)
*   **Banco de Dados:**
    *   MySQL 8.0
    *   Uso de chaves estrangeiras para integridade referencial
*   **Bibliotecas:**
    *   PHPMailer (para envio de e-mails de recuperação de senha)
    *   DomPDF (planejado para geração de PDFs)
